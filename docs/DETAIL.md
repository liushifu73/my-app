# 我的应用（my-app）

最小可用的 DSH 插件骨架。装好后 Agent 多一个 `my_app_ping` 工具，用来确认插件确实加载成功。

## 它做什么

- 注册一个工具 `my_app_ping`，返回插件名、版本和当前 DSH profile。
- 打包了语言包（`locale/en.json`、`locale/zh.json`）和图标（`icon.svg`），插件列表里能看到中文标题和说明。

## 怎么验证

1. 在 **插件** 里确认有一条「我的应用」。
2. 新建一个会话，让 Agent 调用 `my_app_ping`；返回版本号即说明加载成功。

## 限制

这是骨架，还没有实际业务功能。后续要加的功能在这里补充。
