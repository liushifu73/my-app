# 我的应用（my-app）

在 DSH 界面里放一个「文献库」面板，并把文献库信息也给 Agent 用。

## 界面

- 侧边栏底部有一个「📚 文献库」按钮，点开是浮层面板。
- 面板列出文献库根目录、专题数、文献数、已转录数，以及每个专题下的文献清单。
- 每篇文献标两种状态：**已转录**（同目录存在 `.txt`）、**有档案**（存在 `.study.json`）。
- 面板里可以「刷新」和「在访达中打开」文献库目录；按 Esc 或点空白处关闭。

## 给 Agent 的工具

- `my_app_library`：返回同样的扫描结果（专题、文献、转录/档案状态），用来回答「我库里有什么」。

## 数据来源

直接读文献库目录（默认 `~/.dsh-paper-reader/data`），只读不写。
可用插件配置 `dataDir` 或环境变量 `DSH_PAPER_DATA_DIR` 指向别的目录。

## 限制

- 界面文字目前中文为主，英文语言包是附带的。
- 只按「PDF 文件名」认文献；命名不规范的文件不会出现在列表里。
